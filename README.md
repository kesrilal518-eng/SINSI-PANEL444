# SINSI PANEL

Device-Based Sensitivity Generator for Free Fire MAX players.

A completely original Android application built with Kotlin and Jetpack Compose.

## Features

- Device-aware sensitivity recommendations
- Transparent, deterministic calculation engine
- Local profile history (DataStore)
- Copy and Share settings
- Tips and guidance screen
- Premium dark gaming UI
- Fully offline

## Requirements

- Android Studio Hedgehog (2023.1.1) or newer
- JDK 17
- Android SDK 34
- Min SDK 24

## How to run

1. Open the project folder in Android Studio
2. Sync Gradle
3. Run on a device or emulator
4. Build APK via Build > Build APK(s)

Recommendations are starting points only. Always test in training mode.
